# Dark Reflections

## Project Vision

Dark Reflections is a semi-realistic visual novel inspired by Dexter.

This is not a remake of the TV series.

Instead, it is an alternate timeline that explores identity, family, morality and the consequences of choice.

The project aims to deliver the feeling of watching a brand-new season of Dexter.
